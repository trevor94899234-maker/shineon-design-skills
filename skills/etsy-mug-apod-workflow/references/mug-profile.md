# Mug evidence and visual profile

Apply to the actual product. Do not hardcode Everyday Grace, ceramic, 11/15 oz, a single-item offer or two-sided printing into another mug's facts.

## Evidence checks before claiming a feature

| Feature | Evidence needed | Common incorrect shortcut |
|---|---|---|
| Capacity/variant | Actual SKU/capacity label + matching variant/artwork/mockup branch | Rescale 11 oz and relabel 15 oz |
| Quantity | Current owner offer or actual item listing/catalog relationship | Two cups in lifestyle photo means a set |
| Both sides | Named print source, explicit surface/template mapping and actual variant binding | Two duplicated motifs in a file automatically prove physical placement |
| Material/finish/care | Matching official product specification; show source date | Infer ceramic/coating/care from a white image |
| Personalization | Actual editable field/layer mapping and supported instructions | UI maximum 1024 characters proves printable fit |
| Physical dimensions/relative size | Supplier dimensions or calibrated source evidence | Compare differently scaled mockups or apply capacity ratio as height ratio |
| Delivery | Applicable destination/method, source wording, production versus transit | Convert supplier estimate into shop guarantee or add days into fixed arrival |
| Packaging/accessories | Supplied-item facts | Decorative gift box, saucer, flowers or second mug implies inclusion |
| User experience | Real authorized evidence, or clearly suggested use | AI hands/scene imply real customer review, comfort or test result |

Source hierarchy: original design/approved logo establish artwork; actual product mockup establishes this design's digital placement; variant-matched official photography/template supports geometry; supplier specification establishes stated product facts. These types complement one another; none alone certifies physical output or arbitrary buyer-name fit.

## Geometry, light and print inspection

- Preserve the actual silhouette: cup height/width, rim opening, wall taper, base ellipse, handle attachment points, handle opening and handle-to-body ratio. Perspective can explain a visible difference only when supported by the chosen view; do not call an elongated handle “style”.
- Inspect base and outer edge at native size for white fringes, cutout halos, floating contact or inconsistent sharpness. A ceramic specular highlight is not automatically a mask edge; compare its width, continuity and light direction with original source and scene. Diagnose before repeatedly eroding/cropping.
- Check scene illumination, cup highlight direction, shadow softness, contact shadow and reflections together. Keeping the room while pasting an incompatible white-studio cup can remain visibly wrong. An official source with compatible lighting can be researched without asking the owner to find it.
- Preserve exact lettering, sample name, type style, print height/location, motifs and spacing. `EVERYDAY GRACE`, `The Andersons` and `May joy find a home here` were exact source strings only in the historical case. Do not add a heart/star/line, change a house/leaf, or silently replace the brand unit as a repair.
- Inspect a flat PNG on a white QA preview when dark/transparent viewing makes black text invisible. The preview is a diagnostic derivative; retain the original bytes and don't misreport the name as absent.
- Compare 300 px or the intended thumbnail presentation for readable main message, while retaining native-size inspection for fine print. Tiny tagline readability is a separate finding; don't promise every word is legible just because native text is readable.
- Hands/held views need source-supported grip and plausible contact. Do not synthesize an extra passing hand or comfort claim to fill a role. Close details can crop the cup only when the role explicitly calls for it; hero/count roles show a clear complete product.

The default whole-image route can redraw artwork despite detailed references. Prompt precision does not establish pixel identity. When fidelity remains unsolved, follow the stop/decision rules; don't label a visually attractive result exact. An explicitly approved composite test remains only that test, not a standing method switch.

## Configurable twenty-role starting point

Use only if N=20 is the current requested count; adapt roles to supported evidence and actual audience. Keep one source variant per shown cup, and separate facts from suggested contexts. Role substitutions that change an approved brief need the applicable scope decision; missing facts do not authorize invented filler.

| Role | Buyer question | Required source or constraint |
|---|---|---|
| P01 Hero | What am I buying? | Actual product/capacity; one clear complete mug if single-item offer |
| P02 Print close-up | What is the design? | Exact original art and supported front view |
| P03 Name position | Where does my name appear? | Actual editable field location; sample labeled as example when needed |
| P04 Daily use | How does it fit a morning routine? | Plausible single mug use, no comfort/performance promise |
| P05 Housewarming | Why give it for a new home? | Supported design theme; props not included unless verified |
| P06 Seasonal gifting | Could it suit a seasonal occasion? | Actual art unchanged; no automatic Christmas claim for every design |
| P07 Relationship | Who might give it to whom? | Suggested recipient/giver, no fake testimonial or invented hands |
| P08 Quantity | One mug or a set? | Exact offer quantity; size alternatives not extra units |
| P09 Size A | What is this option? | Actual capacity A source, not invented physical measurements |
| P10 Size B | What is the other option? | Actual capacity B source; omit/substitute if no second variant |
| P11 Choice | How do I choose? | Distinct labeled options; uncalibrated panels don't claim relative physical size |
| P12 Print coverage | Is the design on both sides? | Explicit surface mapping; two views remain one item |
| P13 Material detail | What is the surface? | Verified material/finish and useful close detail; complete cup alone may be partial |
| P14 Care | How do I care for it? | Matching official care wording; no invented certification |
| P15 Message | What does the wording mean/say? | Exact original words; no invented Bible attribution |
| P16 Ordering | What name should I enter? | Actual field instructions; spelling/case and unsupported fit limits explicit |
| P17 Customization scope | Which parts can change? | Verified fixed artwork versus editable name |
| P18 Delivery information | What timing information exists? | Applicable qualified supplier/shop evidence; no guaranteed arrival |
| P19 Handle detail | What does the handle look like? | Source-supported angle/detail; no unsupported ergonomic claim |
| P20 FAQ | What final facts remove uncertainty? | Distinct supported questions, not repetitive decorative copy |

This plan is not a demand forecast, universal funnel or mandated 20-image split. Confirm useful coverage against research; keep no more claims than evidence supports. If some role is blocked, finish the other independent roles and prepare a truthful alternative for the actual needed scope decision.
