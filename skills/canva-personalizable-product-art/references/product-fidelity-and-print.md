# Product fidelity and print checks

## Compare at three scales

1. Whole design: same identity, composition, ratio, alignment, hierarchy, and full set of elements.
2. Name region: clean removal, independent replacement text, intact adjacent art, no ghosts or patch.
3. Fine detail at the actual physical print size: legible wording, strong strokes, open gaps, edge quality, and antialiasing on light/dark backgrounds. Use the current supplier/SKU/process minimums when known; do not invent universal pixel thresholds. Dense ornament, microtext, hairlines and tiny isolated details can fail even when a zoomed screen view looks sharp. Recommend a simpler approved revision when needed; never silently simplify the source.

Read every line or transcribe it for comparison. Match spelling, case, punctuation, intentional line breaks, and word counts. Flag unreadable text instead of guessing.

## Required negative checks

- Opaque fill/rectangular patch in the nominally transparent background
- Haze, halos, baked-in checkerboard, remaining name strokes
- Missing/shifted illustration, especially nearby crosses and ornaments
- Cropped borders, stretched artwork, accidental padding changes
- Name flattened with the art in the supposed editable master
- Changed fixed wording or similar-looking text with different meaning
- Long names wrapping/overlapping; short names becoming misaligned
- Diagnostic backgrounds remaining in the exported page

## Separate five quantities

- Native raster pixels: original asset detail
- Canva canvas pixels: editable design coordinate space
- Export pixels: downloaded PNG dimensions
- Delivery pixels: actual file dimensions after transport into the chat, Library, or archive
- Print dimensions: physical output from the applicable supplier specification

Do not infer print size from PNG metadata alone. DPI metadata adds no detail. If physical size is supplied, calculate effective pixels per inch from actual source detail and placement; do not promise generic 300-DPI quality for enlarged raster art.

For the seed journal, the owner supplied a FRONT artwork requirement of 1410 × 2220 px. Verify the current specification for another product/order. Add no invented bleed and do not reinterpret a front as a full wrap.

## Production confidence

A correctly sized transparent PNG may still print poorly. Check the supplier's actual upload preview for placement, trim, contrast, and warnings. A physical sample may be needed for small type, low-detail source art, and color/material interactions. Report these checks pending unless observed; Canva previews are not physical proofs.

## Verify transport separately

A 1410 × 2220 local export and a 1301 × 2048 chat attachment are different files even when they look the same. Record both; inspect the original local export before attributing the difference to Canva or the chat service. Visual color/cleanup checks can pass while delivery dimensions fail. Do not enlarge the received copy as a silent repair. Use a supported original-file or archive route, preserve the measured original export hash, and verify the actual delivered/extracted bytes.

## Treat collateral cleanup changes explicitly

In the seed couples repair, the two unwanted marks were removed, but a localized cleanup changed 1,342 pixels including nearby green/gold artwork edges. Record the changed region and preserve the original. Do not describe this as pixel-identical art preservation, even when the visible cleanup looks good. Disclosure is not approval: keep exact-art-fidelity sign-off pending until the user accepts the alteration or requests restoration.
