# Coach integration without duplicate orchestration

Integrated Etsy Coach is the main decision/drafting entrypoint when available. This existing competitor skill is its evidence collection and audit module; do not create a second competing monolith or ask the user to pick a coach. If the Coach skill is unavailable, use the grounded principles below with their stated limits, and disclose unavailable source context rather than simulating consultation.

Use the current Coach keyword-coach-workflow and seven-layer matrix when available. The saved 2026-10-05 reference package is historical source context; current Etsy rules need current official verification. Source metadata for the four relevant lenses is in [coach-research-sources.json](coach-research-sources.json); do not invent new source IDs or claim to have freshly watched the videos.

## Query design

Define buyer, recipient, sender, occasion, product, use, personalization and desired expression separately. State the decision new evidence could change. Use DYL-A002 customer continuity to ask whether adjacent occasions serve the same customer; use JES-V001 distinct buyer mission to avoid cosmetic variations of the same query. Neither lens proves demand. Preserve existing measured queries and only research actual gaps.

## Review and qualification

Apply STA-A001 experiment discipline: keep source time, metric definition, market and observation window; compare like with like; correct misleading claims now. Product and seller evidence outrank Coach opinion. Shop trading history can support a relevant comparator, not a guaranteed winning niche or profitable product. Preserve uncertain/negative results.

## Keyword selection and field allocation

For each material accept/reject/hold decision, retain phrase/family, exact evidence IDs, product-truth and mission reason, intended field, relevant Coach source ID only when it actually influenced the decision. No quotas or vote counts. A popular wrong-product term is rejected before volume comparison; a missing metric can support hold or a small test, never invented zero demand.

Title communicates the item and essential facts; category/attributes provide accurate classification; tags provide complementary natural intent coverage; description answers buyer questions. Media proves the same offer. A shortened tag is new wording unless separately measured. Recheck official field rules before listing-ready copy. Protect baseline winners and avoid calling exact-title overlap proven cannibalization without first-party performance evidence.

## Learning and originality

Use MEG-V001 to extract an original creative mechanism: emotion, relevance, legibility and proof. Do not copy competitor artwork, wording, layout or whole composition. Record the next controlled experiment and evidence that could change the decision; a new draft can be coherent before complete analytics exist. Later listing edits should preserve a baseline and make interpretable changes.

No performative consultation with all 14 coaches, invented Coach votes, universal sales/keyword cutoffs, or simulated review. Only active, relevant principles with source provenance belong in the decision record. Shop edits, ads, external contact and publication keep their existing owner gates.
