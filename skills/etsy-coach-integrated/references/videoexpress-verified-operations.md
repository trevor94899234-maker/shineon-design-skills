# VideoExpress verified operating path

Evidence date: 18–19 October 2026, VideoExpress 3.5 UI and downloaded private test outputs. Recheck current visible controls and account entitlement before execution; this is a bounded practiced path, not all-function mastery. Official app: https://app.videoexpress.ai/ ; tutorials: https://videoexpress.ai/tutorials/ .

## Choose the operation
- Use the editor for arranging existing media, overlays, durations and export. A static pan proves editor mechanics, not an acceptable emotional product film.
- Use Create Video From Prompt with an existing library image for a reference-guided motion test; validate every visible product frame. Do not let automatic enhancement invent product facts.
- Use a separate saved practice project for unfamiliar effects. Preserve the accepted project's state and source files.

## Editor steps verified in practice
1. Start New and select the task's orientation before layout. The practiced UI exposed Landscape 16:9 and Vertical 9:16; native 1:1 was not established. Square 1080 outputs in the product work were downstream crops/compositions, not verified native square VideoExpress exports.
2. Import via Media Library → My Media → Images → Upload file → Add files when supported for the selected media, or select already authorized media. The observed limits were images 15 MB, audio 100 MB, video 200 MB; inspect current form rather than hardcoding these as universal.
3. Drag media to timeline; trim the right edge; use right-click Resize and Move while preserving proportions. Auto Crop can cut off wide product edges. Filters → Camera Pan → Properties → Setup offers movement choices; assess the rendered output, not just the still preview.
4. Text Animations → Lower Thirds → template → Next → Title/Subtitle/Delay → Next → Result → Add to Timeline. In the practiced UI this appended the text clip at the end, not over the image. Move text to the upper track and overlap it with the lower image/video track; verify rendered timing to avoid a black standalone title tail.
5. Right-click Transition Between → effect → second clip produced arranged overlap and tracks. Resize/Move, Copy/Paste, Opacity, speed change and Dissolve were demonstrated in downloaded lab output. Some Fade In settings did not take effect, and 40 ms black frames occurred at joins/tails. Verify actual frames; a checked control is not proof of successful effect.
6. Save under a distinct name. Save Project As was later exposed by normal browser zoom/layout adjustment and a copy was saved/reopened successfully. Do not force hidden controls. Export Project's control was discovered but editable ZIP download/roundtrip remained unresolved; MP4 is not a project backup.
7. Export Video → filename → selected quality/resolution/format → Create once. The practiced High/FullHD/MP4 path rendered successfully. Track the existing queued output in My Videos; do not resubmit because a download capture times out. Inspect whether download completed; if not, reuse the same visible download link through a permitted normal route.
8. Download and measure actual streams, dimensions, frame rate, duration and bytes. A “no music” export may contain a silent AAC stream; distinguish no audio stream from low-level/silent audio. Preserve original, project identity, output and QA receipts separately.

## Reference-guided standard AI path
1. Create with AI → Create Video From Prompt. Set orientation before Use from Library; an input was rejected when a 9:16 default conflicted with the selected source.
2. Select the exact authorized library image and confirm it is active. Enter the motion prompt; inspect Advanced Mode, Video Only (No Sound) and Manual Video Length where visible. Historical observed slider 3–10 seconds is not a current capability promise.
3. Wait until privacy settings finish loading. Check each form/output's sharing state; a temporary unloaded OFF state was misleading. Do not change account privacy settings without applicable authorization. Verify entitlement/cost for the exact feature, not merely a Commercial/Elite label or a tutorial's “unlimited”.
4. Submit one bounded job; retain its ID and monitor My AI Videos until terminal. Download the same completed output and inspect frames. A prompt requesting static product does not enforce it: drift, changed letters and blinking defects occurred.
5. Use source-preserving video repair only under the current video method and read product-video-fidelity.md. A final 1080-square crop from a 1920×1080 return does not establish a native square setting or recover detail from an enlarged small crop.

## Known useful operations and remaining boundaries
- Save Last Frame was practiced and the downloaded PNG matched the decoded final frame. Separate Audio and Video produced a no-audio video; verify streams rather than relying on mute icons.
- Audio Cutter succeeded through My AI Audio with a generated TTS file. Three nominal parts matched requested durations, but decoded concatenation was shorter by about 66 ms; do not promise lossless/seamless reconstruction. Speech correctness/sync was not established by waveform checks alone.
- Multi-Select Download produced a valid two-MP4 media ZIP. This is not editable Project Export.
- Titles filter had no verified working editor/export after bounded trials; use the verified Text Animations path, not repeated blind drags.
- Creative/Consistent Character agreement screens were not accepted; one dedicated consistent-character path reported UUID empty. Do not use alternate controls to bypass those holds. Fix Subtitles was not tested without an eligible unwanted-subtitle example; printed product words are not subtitles.
- Forty-one available tutorial transcripts were read, not forty-one full videos watched or all features mastered. Keep UI-observed, tutorial-read, submitted, output-produced, QA-pass and owner-accepted separately.
- Service hosting displayed up to 50 days in the observed UI. Keep durable authorized backups; recheck current retention and do not treat the service as permanent storage.
