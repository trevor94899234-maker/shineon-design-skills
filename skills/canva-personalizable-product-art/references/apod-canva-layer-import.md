# Official APOD Canva layer import

Use this route for actual editable/personalizable product artwork, not as a bypass for blocked downloads or access restrictions. Prefer it when the native controls are available and the identified source/destination are authorized. A connected account or design listing alone does not prove editable import.

1. Resolve the exact Canva design ID, title, page and intended product/artwork ID. Inspect the selected page, not just a matching thumbnail. Preserve the original. If changing linked-product art could affect live orders or fulfillment, use an authorized independent private artwork builder and record that it is not linked or saved; do not overwrite the live master by inference.
2. Set the destination canvas to the current verified supplier/SKU dimensions, units and required background. Open the official Add Layers From Canva picker, select the verified page and choose Import Layers rather than a flattened PNG when the intended result is editable. Inspect an uncertain import before repeating it to avoid duplicate layers.
3. Count and inspect the resulting text/image layers. Select each intended personalizable text layer and verify its actual text control, font family/style, rendering and personalization control. Imported vector-named objects may be image layers, not editable vectors. Inspect font-substitution warnings; no warning is not proof of matching fonts or rights. Record fallback and unresolved licensing instead of silently treating them as passed.
4. Compare source and imported composition, exact fixed text, names, size, color, position, scaling, rotation, clipping and layer order. Before accepting any imported personalized artwork, change every custom name to a visibly different example, inspect the actual rendered result, then test short/long names and restore the intended final value. Native editable text can coexist with duplicate old-name outlines or raster glyphs. If old letters remain, inspect the actual selected layer bounds and source images to distinguish duplicate glyph layers from legitimate decorative vectors or a baked-in image. Remove only verified duplicate glyph layers on the authorized private copy; never delete all vector/image layers blindly or erase clean botanical/heart art. Recheck that each new name appears exactly once, surrounding artwork is unchanged, and the saved/reopened product preview and generated mockup agree. Ready status and layer counts alone do not pass this gate. Keep personalized text independent; do not flatten it or enable extra buyer fields without the applicable scope and platform limits.
5. Import is not defect repair. Inspect actual source art for missing pixels, unwanted marks and unintended white/background layers. Preserve intentional white lettering. Repair only the authorized source/copy. When replacing a defective image layer, identify it by actual selection/content, preserve and read back its transform, and compare the whole composition. Record native source dimensions separately from canvas dimensions; import/enlargement creates no new detail.
6. Verify the intended canvas background/alpha and final exported bytes where an export is required. An alpha control or checkerboard is not a clean-alpha file test. Keep the editable master and any necessary final production export separate. Do not require a premature flattened PNG merely to perform an available editable import.
7. Save only in the authorized destination. Confirm the save result, reopen/reload safely and verify artwork ID, canvas, layers, text/personalization, transforms and actual persistence. An unsaved successful import is only an import/editability result, not a saved APOD product. Do not publish Etsy, change prices, link production art or claim production readiness as a side effect.
