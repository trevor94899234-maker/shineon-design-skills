## Apply the lessons at the correct stage

1. Before a batch, perform early product/print triage, preserve original artwork and explain the exact blocker. Separate print-art masters, supplier previews, gallery derivatives and video outputs with independent versions/status. C2's 1374×1145 source placed at60×50 inches is about22.9 effective PPI; its5760×4800 template is96 PPI. Enlargement does not create96-PPI source detail. C1 source detail/white-ink/substrate and C3 physical color/alpha/safe-area checks remain independent of numerical resolution. Don't manufacture a universal acceptable-PPI threshold.
2. Keep one browser operator across the shared surface. Runtime failure, stale/empty tab, logged-out state, missing action authorization and user handoff require different next steps. Use actual state and exact errors, respect denied actions and user control, and don't repeatedly ask for the same valid scoped authorization. Source artifacts confirm runtime recovery, but this review did not replay the old-tab failure or independently diagnose its root cause.
3. Prove one representative production/export/upload route, then batch against one mapping. At completion reconcile every role/file/version/asset/order/hash; count files, distinct accepted roles, saved selections, duplicates and HOLDs separately. Keep transformed remote bytes distinct from exact-byte matches. Never let a success toast or a workers' prepared-file count stand for persistence.
4. Use current specialist visual rules rather than duplicating them. Retain editable name hierarchy and exact fixed text; original faith messages with Bible references are not literal quotations. Preserve honest native dimensions. Explanation cards solve explanation roles; believable UGC-style scenes require scene fidelity and naturalness, not conversion of every role into a card.
5. Inspect native video capability per product, retain two-if-supported/otherwise-at-least-one, measure the downloaded final file and inspect worst-crop frames. A cropped12-second candidate is not repaired by renaming or checking only the first frame. A6/8-second final can be accurately delivered with its measured duration while any creative gap stays open.
6. After mockup-first, reuse the Vault and dated overlays before querying gaps. The six-phrase USA/Etsy eRank batch consumed one observed quota unit in the recorded run; don't generalize pricing/quota. Preserve Unknown, <20, observed zero, UI dash and CSV conversion differences. The bride gift from mom831 average and Sep2026 point10 remain different evidence; no monthly-hot or tag-to-sales causal claim.
7. Update the user's current chat when a material result or correction is known, then verify each requested data destination separately. Formal cloud skill saved, local Vault updated, Dashboard imported/applied, APOD persisted and Etsy live are different state transitions. A saved audit, conversation summary or sidecar only proves its own destination.
