# Continue research without repeating it

## Execution card for an existing project
1. Read the complete current brief, handoff, raw query batches and audit excerpts. Build one exact-query ledger across all of them. A copy-ready text shortlist is not the full history; excluded terms may already have been researched.
2. Record completed source clusters and specific evidence gaps. Do not reopen every named shop or rerun every query merely because it appears in the handoff.
3. Inventory authorized browser tabs; inspect the existing target page and use it when correct. If a new page is necessary, open only the verified source URL or one focused query within current scope. Avoid entering private Shop Manager during public research.
4. For a bounded research pass, record parameters before action: SERP page limit, plausible-results limit, gap-only listings, new listings, unresolved shops, new-query budget, and stop condition. The historical case below used one SERP page, first five plausible results, two identified gaps, up to two new pages, at most three unresolved shops and at most five genuinely new keyword phrases. These are an example budget, not universal requirements.
5. On the search page, verify query and visible country/shipping/Bestseller filters. Capture displayed count, sponsored count, sort order, each item's badge versus ad status, listing URL, title, seller, price/currency/variant, visible stars and whether review count belongs to item or shop. Do not equate sponsored with bestseller. A filter UI unavailable on this screen is a limitation, not permission to invent a query parameter.
6. Fill identified missing fields on exact pages. For materials, inspect Item details or equivalent current visible authoritative field. For tag strings, inspect an available authorized audit. `13/13` proves count, not strings. If strings remain unreadable, record unavailable and stop that gap.
7. For each new competitor, collect only relevant product/personalization/specification/shipping/returns/review/image fields. Keep direct versus adjacent comparisons explicit. Do not silently carry old shipping promises into a current pricing comparison.
8. Inspect at most the authorized unresolved shop sample. Historically observed eRank route: Competitor Research → Shop Info; search one actual public shop name at a time via current visible controls. Capture store-level metrics, rank, tags/categories, observation date and no-data warnings. Store totals/tags never become one listing's totals/tags.
9. If requested, describe one useful image's original design principles: cover legibility, name hierarchy, props, background, personalization explanation and image order. Do not reproduce competitor artwork or entire composition.
10. Deduplicate candidate query text against the full ledger before submission. Research only the remaining budget. For each query preserve source of discovery, exact spelling, country, check date, trend month, searches, clicks, CTR, competition, KD, qualifiers and warnings. Use at most one level of related suggestions for a focused pass; do not expand indefinitely.
11. Separate product fit, measurable keyword evidence, source disagreement and hypothesis. No ranking by competition alone. A cover Bible verse does not establish prayer/devotional/Bible-study interior content.
12. Stop when the agreed SERP and new-query batch are captured or blocked, and candidates can be ranked with caveats. Deliver one next action and what new evidence would change it. Do not keep searching to inflate sample size.
