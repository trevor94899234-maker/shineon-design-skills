## Authority and evidence order

Resolve conflicts in this order:

1. Current Etsy official documentation for Etsy policy and search behavior.
2. Current first-party Etsy data supplied by the owner, such as Shop Stats, search terms, listing data, or screenshots.
3. The owner's current explicit project decisions and the current Dashboard state.
4. Historical workshop transcripts and personal project memory as heuristics.
5. eRank, EverBee, or other third-party estimates as supplemental signals only.

Authority is claim-specific: a provider’s first-party documentation governs what its own metric is defined to mean, never Etsy policy or actual shopper demand. Current product records govern deliverable facts; no coach, provider score or council vote overrides them.

Always label facts as **confirmed**, **estimated**, **inferred**, **test hypothesis**, **missing**, **invalid**, or **stale** when that distinction affects the decision. Never turn a historical number, screenshot-only value, autocomplete suggestion, or third-party estimate into a guaranteed demand, ranking, sales, or compliance claim.

For current Etsy rules, search behavior, fees, IP, supplier facts, image limits, or platform features, verify current authoritative sources before stating a conclusion as current. If an older memory conflicts with current official guidance, keep the memory as historical context and follow the current source.
